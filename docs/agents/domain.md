# 领域术语

本仓库使用一份公开的[术语表](../GLOSSARY.md)，统一文档、讨论与代码中的领域用语。本文说明如何阅读和使用它，适用于所有贡献者，无需安装特定 skill。

## 词条格式

词条以中文名称为主，附已确定的英文名，定义使用中文。游戏内官方中文专名沿用原名，没有英文名时可以省略。相关词条可按领域分组。

```markdown
**中文名称（English Term）**:
一至两句定义，说明概念及容易混淆的区别。
_避免称呼_: 容易被误用为同一概念的其他称呼
```

“避免称呼”为可选项，仅适用于该词条所定义的概念。定义中可以链接其他词条来表达概念之间的关系。

## 使用术语

- 涉及领域概念的设计、实现或审查，先阅读术语表中的相关定义。
- 中文文档、Issue、PR 和讨论使用词条的中文名称。代码标识符和英文讨论使用对应英文名，代码符号按原样引用。
- 按定义区分概念，避免在同一语境中用不同称呼指代同一概念。例如，描述用户设置时使用“设置”，其他语境中的构建配置仍可称为“配置”。
- 术语表描述领域含义。具体行为和操作方式查阅对应文档。
- 发现代码或文档与定义存在差异时，明确指出所涉及的词条及差异，避免把不同含义当作同一概念使用。
