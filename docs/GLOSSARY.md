# Open Endfield Assistant

本词汇表统一 OEA 的领域用语。

## 设置与配置

**设置（Settings）**:
跨运行持久化并影响应用行为的可变状态，通常由用户编辑，也包含与用户选择相关的状态。
_避免称呼_: Config、Configuration

**配置（Configuration）**:
在一次构建或运行中固定、不随用户交互修改的不可变输入，用以区别于可修改的设置。

## 自动化

**自动化任务（Automation Task）**:
连接游戏窗口，通过截图获取输入信息，通过 OCR、模板匹配等解析信息，通过鼠标点击、键盘事件等操控游戏窗口，完成游戏内的操作任务。无需人工介入。

## 档案与扫描

**档案扫描（Archive Scan）**:
自动化任务的一种，遍历档案详情页面并产生扫描记录，通过档案匹配判断当前账号对各个档案的收集情况。

**档案（Archive）**:
游戏内的一份具体档案，由稳定且唯一的档案标识区分，标题相同不代表是同一个档案。档案详情页面每次只展示一个档案。

**档案页面（Archive Page）**:
档案库的三个大页面：音像存档、见闻辑录、中枢档案。

**档案详情页面（Archive Detail Page）**:
展示单个档案标题与内容的游戏页面，是扫描识别的对象。

**档案分类（Archive Category）**:
档案页面下的分类：多媒体、纸质记录、电子档案、藏品、中枢档案、调查报告。

**档案目录（Archive Catalog）**:
反映对应游戏版本中档案事实的只读常量数据结构，表示档案集合及其档案页面、档案分类组织关系，保留档案顺序、标题及获取方式。

**扫描记录（Scan Record）**:
对单个档案详情页面进行一次识别产生的一条观察记录，包含截图、识别文本及所在档案分类。

**扫描结果（Scan Results）**:
一轮档案扫描逐步产生的扫描记录集合，可以包含零条、一条或多条扫描记录。

**档案匹配（Archive Matching）**:
一组扫描记录与档案目录中各个档案之间的关联，每条扫描记录可以匹配零个、一个或多个档案，同一档案也可以匹配多条扫描记录。当前匹配算法以标题为主要依据，并限定在同一档案分类内，因此同分类下标题重复的档案可能关联到同一条扫描记录。

## 应用形态与发布

**开发版（OEA dev）**:
通过 `tauri dev` 编译运行的 OEA 应用形态，不受优化等级影响。

**发行版（OEA release）**:
通过 `tauri build` 编译得到、供独立运行与分发的 OEA 应用形态，不受优化等级影响，也不以是否已由项目正式发布作为分类条件。
_避免称呼_: OEA stable、正式版

**已发布版本（Published Version）**:
由 OEA 项目正式发布、有对应发布记录的版本。

**最新发布版本（Latest Published Version）**:
OEA 项目当前最新的已发布版本，与用户正在运行的版本分别描述。当前版本可能等于、落后于或领先于最新发布版本。

**可用更新（Available Update）**:
适用于当前应用、版本号高于当前运行版本的已发布版本。最新发布版本不一定构成可用更新。
