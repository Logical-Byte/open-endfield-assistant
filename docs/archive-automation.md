# 档案库自动化

本文档记录档案扫描依赖的游戏 UI 事实、用户可见操作和档案扫描业务流程。坐标、模板和界面名称以游戏当前版本为准；修改档案库相关自动化时，请同步核对本文档。

## 扫描启动提示的版本机制

首次进入「档案扫描」页时，应用会展示一份操作指引（分辨率 1280 × 720、关闭 HDR、打开档案库等）。为避免每次启动都打扰用户，提示的展示与否由「提示版本号」控制。

两个版本号配合决定是否展示：

- **当前提示版本**：前端常量 `CURRENT_SCAN_TIPS_VERSION`（`src/components/scan/ScanGuide.vue`），与提示文案写在同一个文件里，保证改文案时不会漏改版本。
- **用户已确认版本**：后端配置字段 `scanTipsDismissedVersion`（`config/oea_config.json`，默认 `0`）。用户勾选「下次更新前不再提示」并点击「我知道了」时写入。

展示规则：`scanTipsDismissedVersion < CURRENT_SCAN_TIPS_VERSION` 时展示提示，否则不展示。

- 不勾选、直接点「我知道了」：仅本次启动隐藏（内存标志），不写配置，下次启动仍展示。
- 勾选后点「我知道了」：把 `scanTipsDismissedVersion` 写入当前 `CURRENT_SCAN_TIPS_VERSION`，由 `src/utils/app/config.ts` 的配置深监听自动落盘，本版本内不再展示。

### 更新提示文案，让所有用户重新看一次

1. 修改 `ScanGuide.vue` 中的提示文案；
2. 把 `CURRENT_SCAN_TIPS_VERSION` 递增 1（例如 `1 → 2`）。

老用户已确认的版本号（`1`）将小于新版本（`2`），下次启动会重新看到新提示；从未确认过的新用户（`0 < 2`）同样会看到。

此操作只改前端常量与文案，不涉及 config 结构，**无需** bump `minorVersion`。

### 更新提示文案，但无需老用户重看

只修改 `ScanGuide.vue` 中的提示文案，保持 `CURRENT_SCAN_TIPS_VERSION` 不变。已确认过的用户（版本号 ≥ 当前版本）不会重新看到；只有从未确认过的新用户会看到最新文案。

> 说明：`scanTipsDismissedVersion` 字段本身属于配置兼容变更，首次新增该字段时 bump 了一次 `minorVersion`（当前为 `1`）。后续只改动版本号的「值」不构成结构变更，不要再 bump。

## UI 状态约定

- **具体 UI 状态**代表游戏当前所处的一个确定界面，可以作为导航的起点或目的地。
- **状态组**代表多个具体 UI 状态共有的可观察特征，用于复用分层判定条件，不作为导航目的地。
- **未识别结果**表示当前画面无法由已有判定得到具体 UI 状态，不属于具体 UI 状态。
- 所有坐标均以 1280 × 720 画面为基准，截图在识别前缩放到这个分辨率。
- `ROI(l, t, r, b)` 表示 `ltrb` 矩形，左上角为 `(l, t)`，右下角为 `(r, b)`。
- `ROI_LTWH(x, y, w, h)` 表示 `ltwh` 矩形，左上角为 `(x, y)`，宽度为 `w`，高度为 `h`。
- 除非另有说明，模板匹配阈值为 `0.75`。
- “匹配模板”表示在指定 ROI 内找到达到匹配阈值的模板。
- 灰度均值小于 `128` 时，ROI 判定为深色；灰度均值大于或等于 `128` 时，ROI 判定为浅色。
- 依赖状态组的判定条件只在其先决状态组成立后继续计算。

## 导航转移约定

- 导航只使用具体 UI 状态作为节点，状态组不参与导航。
- 每条转移描述“在来源状态执行一个操作后，操作成功时可能观测到的下一状态集合”。
- 动作失败或 UI 没有响应时可能停留在来源状态，这种情况不重复列为每条转移的原地自环。
- 只改变同一界面内容、不改变具体 UI 状态的业务操作不列为导航转移。例如「下一篇」和档案详情右箭头仍然停留在档案详情页面。
- 一个操作对应多个可能状态时，表示仅凭当前画面和操作无法预先确定唯一结果，不表示游戏随机选择结果。

1. 档案详情页面；

判定顺序属于当前兼容行为。当多个状态的条件意外同时成立时，排在前面的状态优先。

## 档案扫描流程

档案扫描按以下顺序处理六个子分类：

1. 「音像存档 - 多媒体」；
2. 「见闻辑录 - 纸质记录」；
3. 「见闻辑录 - 电子档案」；
4. 「见闻辑录 - 藏品」；
5. 「中枢档案 - 中枢档案」；
6. 「中枢档案 - 调查报告」。

导航负责抵达上述具体 UI 状态以及进入、离开档案详情页面。档案扫描业务负责 OCR、标题纠错、结果上报、扫描顺序，以及详情页面内的「下一篇」和左右箭头操作。

## 如何扫描一个子分类中的所有档案

进入子分类后，点击第一份档案的位置 `(401, 182)` 进入档案详情页面。随后对当前详情页面重复以下步骤：

1. 在 `ROI_LTWH(350, 58, 578, 42)` 对档案标题进行 OCR，把识别结果写入日志并上报扫描结果；
2. 在 `ROI(762, 654, 925, 711)` 搜索「下一篇」按钮。找到后点击，进入下一份档案详情；
3. 如果没有找到「下一篇」，在 `ROI(1206, 313, 1276, 423)` 搜索「情报档案库/档案详情右箭头」按钮。找到后点击，进入下一份档案详情；
4. 如果两个按钮都没有找到，当前子分类扫描完成，关闭档案详情页面返回子界面。

「下一篇」和「档案详情右箭头」只改变详情页面中展示的档案内容，当前具体 UI 状态仍然是「档案详情页面」。
