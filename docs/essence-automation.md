# 基质扫描

基质扫描读取贵重品库的武器基质，展示三个属性、各自等级、稀有度、锁定与弃用状态，
并根据启动时已保存的规则给出保留建议。扫描不会更改游戏内锁定、弃用标记或执行分解。

## 使用

1. 将游戏客户区设为 **1280×720**，使用简体中文并关闭 HDR。
2. 按 `N` 打开贵重品库，进入「武器基质」。清除筛选，使整个背包的基质都出现在列表中。
3. 在 OEA「基质扫描」中检查保留规则，然后开始扫描。扫描器会先将列表滚回顶部。
4. 扫描期间保持游戏界面和排序不变。停止按钮与全局停止入口会结束扫描，并保留已收到的结果。

结果只保存在本次应用会话中。重新启动基质扫描会替换上一轮结果。位置中的行号是从
背包顶部开始的绝对行号，列号从 1 到 9。保留、建议丢弃、跳过、待确认均有具体原因。

## 规则

规则是 `essence::evaluate` 的纯函数输入，不访问窗口、设置文件或任务状态。
`ScanSettings` 保存在 `config/oea_config.json` 的 `essenceScan` 字段内。
旧设置文件缺少该字段时使用默认规则。每轮扫描固定使用开始时的设置快照。

依次判断：

1. 启用「保留已锁定」时，已锁定的基质保留。
2. 启用「跳过已弃用」时，已弃用的基质跳过。
3. 非无瑕处理设为跳过时，高纯与其他已知稀有度跳过。
4. 属性、等级、稀有度或标记识别不完整时，显示待确认。
5. 完整匹配自定义的主属性、次属性、技能组合时保留。
6. 启用高等级保留时，任一属性达到其类型的阈值即保留。
7. 完整匹配至少一把未被排除的武器时保留。
8. 其余基质建议丢弃，并区分「没有匹配武器」与「匹配武器均被排除」。

武器匹配按属性的语义类型归并，支持三个属性在画面中改变排列顺序。
主属性和次属性的等级范围为 1 至 6，技能等级范围为 1 至 3。
默认处理非无瑕基质、保留已锁定，未启用高等级保留和自定义组合。

## 扫描实现

代码入口为 `src-tauri/src/automation/essence_scan/`。

- `layout.rs`：720p 固定像素位置，9 列、约 104 像素行距。
- `recognition.rs`：属性和按钮模板匹配、等级亮点计数、稀有度色相识别、卡片占用检测。
- `pagination.rs`：比较翻页前后网格的重叠区域，测量内容实际移动的像素数。
- `workflow.rs`：回到顶部，逐行点击、识别、判断与上报，滚动后继续未访问的行。
- `worker.rs`：连接游戏和检查实际分辨率，沿用 OEA 任务生命周期与停止令牌。
- `simulation_worker.rs`：无需游戏的固定样例，使用相同保留判断函数。

每次向上拖动约三行并保留两行重叠。扫描游标使用背包行列位置，两个属性完全相同的
基质会分别记录。尾页按观测到的实际位移处理。滚动条到底后完成扫描。
无法确认滚动位移、画面不再属于基质页面、窗口尺寸变化或拖动无效时，任务结束并说明原因，
已上报的结果仍可查看。单轮最多推进 500 次视口，达到限制会报告失败。

自动化运行的 `runId` 由 Runtime 分配，生命周期与领域事件共同携带该 ID。
前端拒绝上一轮迟到的结果。Worker 和纯规则函数无需生成或保存运行 ID。

## 资源与校准

属性目录固定在 `src-tauri/src/essence/catalog.json`，模板固定在
`src-tauri/assets/essence/` 并编译进程序，无需另行更新资源子模块。
来源版本和许可见 [第三方组件](third-party-notices.md)。

更新目录：

```bash
python3 scripts/importEssenceCatalog.py /path/to/eer-resource
```

重新从 EER 的 1080p 模板生成 720p 文件：

```bash
uv run --with pillow python scripts/importEssenceTemplates.py /path/to/endfield-essence-recognizer
cargo fmt --manifest-path src-tauri/Cargo.toml --all
```

本次验证包含真实内置模板拼接出的合成详情图，以及 73 枚基质的合成背包：从列表中部
回到顶部、跨页重叠、部分尾页、空槽、相同属性的多个基质和中途停止。
这些测试验证算法与事件行为。真实游戏的字形、亮度、卡片占用阈值和布局仍需要
Windows 720p 实机校准。若高度重复的网格图像无法唯一确定翻页位移，扫描会报告位置无法确认。

## 模拟与本地检查

在「设置 → 开发者选项」开启「模拟基质扫描」，再到基质扫描页开始。
约 20 秒产生 54 条固定样例，覆盖匹配、未匹配、锁定、弃用、非无瑕、高等级与识别缺失。
模拟使用当前已保存的规则，因此修改规则后重新运行会改变判断。模拟开关在重启后关闭。

```bash
pnpm tauri dev
cargo test --manifest-path src-tauri/Cargo.toml automation::essence_scan --lib
```

Windows 目标的编译检查仍使用 [后端规范](rule-backend.md) 中的命令。
